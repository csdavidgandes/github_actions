# github_actions

Proyecto de ejemplo (Módulo 7 - Agile) para practicar CI con GitHub Actions.

## Estructura

```
src/mi_proyecto/   Código fuente
tests/             Pruebas unitarias
```

## Instalación

```bash
python3 -m venv venv
source venv/bin/activate
pip install -e .
pip install pytest
```

## Ejecutar pruebas

```bash
pytest
```
